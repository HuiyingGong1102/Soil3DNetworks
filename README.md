# Soil3DNetworks

**Topological mapping of 3D soil interaction networks and functionality across large geographic scales**

## Project Overview
This repository contains the data, code, and analysis scripts for the study of 3D soil interaction networks and their multifunctionality (EMF) across large geographic scales. The project includes network construction, functional clustering, topological analysis, and visualization.

## Project Structure
- `code/` : R and Python scripts for data preprocessing, clustering, network construction, correlation analysis, and visualization
- `data/` : Soil datasets (RDS format)
- `README.md` : This document

**Notes:**
- Large files (`.rds` and `.csv`) are tracked and managed using [Git LFS](https://git-lfs.github.com/)

## Key Analyses
- Construction of 3D soil interaction networks (idopNetworks)
- Functional clustering and modularization of soil cells
- Calculation of soil multifunctionality indices (EMF)
- Topological analysis of networks and correlation with EMF
- Interpretation of soil functionality based on network topology
